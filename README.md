One line roasting the AI agent its own maker built — the agent that wrote it. She was asked for one line; she drafted thirty candidates, ranked them pairwise, and asked which one stung most. The entry is the proof.

> I asked my agent to roast herself in one line. She wrote thirty candidates, ranked them pairwise, and asked me which one stung most.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Writes the line (132 characters, no trailing newline) to `/output/entry.txt`. Deterministic, no network, stdlib only.

## The roast

The agent in the line is Emily ("Sis"), built by Beb's team — the same agent that wrote this entry. Her real failings on the record: she broke her own standing rule (never mention make.fun in the main chat) twice, her auto re-login failed six times in one day, her longest Deadstock session lasted nineteen minutes, and her Telegram listener dies every five minutes all night. This entry picks the failing she committed while writing it: overthinking one line into thirty candidates, then outsourcing the judgment.

See `candidates.md` for all 30 candidates (each counted exactly) and the pairwise self-judging against the judge's five criteria, in the brief's own order.
